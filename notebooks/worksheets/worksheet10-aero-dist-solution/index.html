The normal distribution¶

Recall the definition for the normal distribution

N(α;μ,σ)=1σ2πexp⁡[−(α−μ)22σ2]\mathcal{N}(\alpha;\mu,\sigma) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left[-\frac {(\alpha - \mu)^{2}} {2\sigma^{2}}\right]N(α;μ,σ)=σ2π​1​exp[−2σ2(α−μ)2​]

In python we can write this as

def normal(alpha,mu,sigma):
    out=(1/(sigma*np.sqrt(2*np.pi)))*np.exp(-(alpha - mu)**2./(2*sigma**2.))
    return out

The lognormal distribution¶

For a lognormal distribution, the variable that is normally distributed is α=ln⁡x\alpha = \ln xα=lnx. This distribution arises because processes that create the end value (like the mass of areosols) are multiplicative instead of additive. That is, while a normal variable is generated by the sum of many random variables (the central limit theorem) a lognomal variable is generated by the product of many random variables

N(ln⁡(x);μ,σ)=1σ2πexp⁡[−(ln⁡(x)−μ)22σ2],  x>0.\mathcal{N}(\ln(x);\mu,\sigma) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left[-\frac {(\ln(x) - \mu)^{2}} {2\sigma^{2}}\right], \ \ x>0.N(ln(x);μ,σ)=σ2π​1​exp[−2σ2(ln(x)−μ)2​],  x>0.

Note that it’s a little more complicated than just swapping α=ln⁡x\alpha = \ln xα=lnx. Recall that a change of variables has to conserve area, i.e.:

N(α,μ,σ)dα=N(ln⁡x,μ,σ)dα=f(x)dx\mathcal{N}(\alpha, \mu, \sigma) d\alpha= \mathcal{N}(\ln x, \mu, \sigma) d\alpha = f(x)dxN(α,μ,σ)dα=N(lnx,μ,σ)dα=f(x)dx

and since:

dα=dα=dxxd\alpha = d \alpha = \frac{dx}{x}dα=dα=xdx​ this means:

N(ln⁡x,μ,σ)dα=f(x)  dα  x\mathcal{N}(\ln x, \mu, \sigma) d\alpha = f(x)\; d\alpha \; xN(lnx,μ,σ)dα=f(x)dαx so that:

f(x)=1xN(ln⁡x,μ,σ)=1xσ2πexp⁡[−(ln⁡(x)−μ)22σ2]f(x) = \frac{1}{x} N(\ln x, \mu, \sigma) = \frac{1}{x \sigma\sqrt{2\pi}} \exp\left[-\frac {(\ln(x) - \mu)^{2}} {2\sigma^{2}}\right]f(x)=x1​N(lnx,μ,σ)=xσ2π​1​exp[−2σ2(ln(x)−μ)2​]

In python:

def lognormal(x,mu,sigma):
    """
    parameters
    ----------
    x: vector (float)  
      aerosol masses (kg)  (for example)
      
    mu: float
       log(mean mass)
       
    sigma: float
       log(standard deviation)
       
    returns
    -------
    
    out: vector (float)
        lognormal pdf, normalized to 1
        units
    
    """
    out=(1/(x*sigma*np.sqrt(2*np.pi)))*np.exp(-(np.log(x) - mu)**2./(2*sigma**2.))
    return out

It’s an observational fact that aerosol masses tend to follow a lognormal distribuiton.

As a specific example take:

1. Mean aerosol mass μ=2×10−17\mu = 2 \times 10^{-17}μ=2×10−17 kg

2. Log of the standard deviation = ln⁡1.7\ln 1.7ln1.7

3. Total mass of aerosols = 10−9  kg  m−310^{-9}\; kg\;m^{-3}10−9kgm−3 = 1 μg  m−3\mu g\;m^{-3}μgm−3

4. Aerosol density 1775 kg m−3kg\,m^{-3}kgm−3

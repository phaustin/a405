Course policy for generative AI

Effective AI Use: We all use AI and we all know that AI can be anything from amazingly helpful to a frustrating waste of time! AI should enhance, not replace, your learning process. The goal of this course is for you to be able to use Python to assist you in addressing scientific problems during and beyond your degree. Thus AI should not be used to replace the basic problem-solving required to write code for any lab. Nor should it be used to produce code that you could not come up with yourself.

Documenting AI Use: If you use AI in a lab / project you MUST (1) transparently and precisely document that usage at the specific locations in your code in which it is used, including specific tools and contributions (e.g., ‘ChatGPT provided the following code (and give this) which I adapted as written on lines XX-YY below’), (2) Critically evaluate and refine AI-generated outputs to demonstrate your understanding e.g. via comment lines written BY YOU, not AI. We may ask you to explain in person how you arrived at a particular coding solution or how it works to be able to demonstrate your understanding.

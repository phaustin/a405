Notebook practice¶

Write a function called “eqstate” that calculates the density of dry air. Use it to find the dry air density at a pressure of 80 kPa and temperatures of temp=[270, 280, 290] K

def eqstate(Temp,Press):
    dens = xxx
    return dens

Answer¶

import numpy as np

Rd = 287 #J/kg/K
def eqstate(temp,press):
    """
    Parameters
    ----------
    
    temp: float
         temperature (K)
    press: float
         press (Pa)
         
    Returns
    -------
    
    dens: float
         dry air density (kg/m^3)
    """
    dens = press/(Rd*temp)
    return dens


dots = '*'*60
the_temps = np.array([270, 280, 290]) #K
press = 80.e3 #Pa


#
#  loop over temps
#
for temp in the_temps:
    dens = eqstate(temp,press)
    output = f"""
          {dots:}
          At pressure {press:6.0f} Pa and temperature {temp:6.2f} K 
          the air density is {dens:6.3f} kg/m3
          {dots:}
          """
    print(output)

Assignment 1 Solution¶

The figure below represents an insulated box with two compartments A and B, each containing dry air. They are separated by an insulating and perfectly flexible wall, so that the pressure is equal on the two sides. Initially each compartment measures one m3m^3m3 and the gas is at a pressure of 100 kPa and a temperature of 273 K. Heat is then supplied to the gas in box A using a resistor, until the pressure in both compartments rises to 300 kPa. Calculate:

  1. The final temperature TBT_BTB​ (K) in box B

  2. The time integrated work (J kg−1J\,kg^{-1}Jkg−1) performed on the air in B by the membrane.

  3. The final temperature TAT_ATA​ (K) in box A

  4. The time-integrated heating rate (Jkg−1J kg^{-1}Jkg−1) of the gas in box A.

Hint: use the fact that entropy (and therefore θ\thetaθ ) is conserved for an adiabatic process and therefore can’t change in compartment B, and that the total volume of the combined compartments A and B has to stay constant at 2 m3m^3m3.

First write two convenience functions to calculate temp given θ\thetaθ¶

Test them by going from temp to θ\thetaθ then back to temp

def theta_from_temp(temp,press):
    """
       Input: temp (K)
               press (kPa)
       Output: theta (K)
       Thompkins eq. 1.38
    """
    cpd=1004. #J/kg/K
    Rd = 287.  # J/kg/K
    p0 = 100   #kPa
    theta = temp*(p0/press)**(Rd/cpd)
    return theta

def temp_from_theta(theta,press):
    """Input: theta (K)
               press (kPa)
       Output: temp (K)
    """
    cpd=1004. #J/kg/K
    Rd = 287.  # J/kg/K
    p0 = 100   #kPa
    temp = theta/((p0/press)**(Rd/cpd))
    return temp
    
theta = theta_from_temp(273.,100.)
Tinitial = temp_from_theta(theta,100.)

print(f'test roundtrip for theta: theta={theta} K, Tinitial={Tinitial} K')
